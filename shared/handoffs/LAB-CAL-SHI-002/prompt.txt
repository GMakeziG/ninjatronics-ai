## Approved Architecture
- Dedicated namespace: calibre
- Base + production overlay Kustomize pattern (study kubernetes/apps/base/audiobookshelf/ and kubernetes/apps/production/wallabag/ for patterns)
- PVCs: calibre-config (2Gi), calibre-library (100Gi), local-path, RWO
- Node placement: nodeSelector kubernetes.io/hostname: niner
- Strategy: Recreate (single replica, RWO storage)
- Security context: runAsNonRoot true, runAsUser 10001, runAsGroup 10001, fsGroup 10001, seccompProfile RuntimeDefault, allowPrivilegeEscalation false, capabilities drop ALL
- Service: ClusterIP, port 8080
- Auth: calibre-server --enable-auth --userdb
- Secrets via OpenBao at secret/apps/calibre + ExternalSecret in production overlay
- Ingress: internal hostname only (e.g. calibre.internal.ninjatronics.io or calibre.local), NO .ninjatronics.io public hostname, NO Cloudflare Tunnel route

## Image Requirements (Option B — Ninjatronics-owned minimal)
- Dockerfile in the repo (e.g. kubernetes/apps/base/calibre/image/ or a top-level calibre-image/ directory)
- Debian trixie-slim base pinned by digest
- Official Calibre binary, version pinned (find the latest stable release)
- Downloaded tarball SHA-256 verified during build
- Non-root UID/GID 10001:10001
- calibre-server only — NO desktop, VNC, X11, Wayland, terminal
- Port 8080 only
- Build the image with docker, tag it (e.g. ghcr.io/ninjatronics/calibre:<version> or localhost/calibre:<version> for local k3s)
- Load into k3s if no registry is available (docker save | k3s ctr images import, or k3s image import)
