## Scope
Review these security dimensions against the ACTUAL deployed state:

1. Container image security:
   - Dockerfile at containers/calibre/Dockerfile
   - Base image pinned by digest
   - Calibre tarball SHA-256 verified
   - Non-root runtime (UID 10001)
   - No desktop/VNC/X11/Wayland services
   - Minimal attack surface

2. Kubernetes security context:
   - runAsNonRoot, runAsUser, runAsGroup, fsGroup
   - seccompProfile RuntimeDefault
   - allowPrivilegeEscalation false
   - capabilities drop ALL
   - No hostPath, hostPID, hostIPC, hostNetwork

3. Network security:
   - ClusterIP only (no LoadBalancer/NodePort)
   - Port 8080 only
   - No public exposure (no Cloudflare DNS, no cloudflared route, no .ninjatronics.io hostname)
   - Ingress is internal only (calibre.internal)

4. Secret management:
   - ExternalSecret synced from OpenBao
   - No plaintext secrets in Git
   - Secret keys match expected pattern
   - OpenBao path: secret/apps/calibre

5. Storage:
   - PVCs use local-path (RWO)
   - No hostPath mounts
   - PVC sizes appropriate (config 2Gi, library 100Gi)

6. GitOps integrity:
   - Flux reconciled to the correct revision
   - No manual kubectl apply overrides
   - Manifests match between Git and cluster

7. Authentication:
   - calibre-server --enable-auth enabled
   --userdb configured
   - Unauthenticated access to protected endpoints returns 401

## Validation Commands to Run
```bash
export PATH="/home/linuxbrew/.linuxbrew/bin:/home/linuxbrew/.linuxbrew/sbin:$PATH"

# Review the actual deployed manifests
kubectl get deployment -n calibre calibre -o yaml
kubectl get pod -n calibre -l app.kubernetes.io/name=calibre -o yaml
kubectl get service -n calibre -o yaml
kubectl get ingress -n calibre -o yaml
kubectl get pvc -n calibre -o yaml
kubectl get externalsecret -n calibre -o yaml
kubectl get secret -n calibre -o jsonpath='{.items[*].type}'  # don't print values

# Check for any cloudflared routes
kubectl get configmap -n platform cloudflared-config -o yaml 2>/dev/null | grep -i calibre

# Verify no public DNS exists
kubectl get ingress -A | grep -i calibre

# Check the Dockerfile
cat containers/calibre/Dockerfile

# Verify the entrypoint
cat containers/calibre/entrypoint.sh

# Check pod security context
kubectl get pod -n calibre -l app.kubernetes.io/name=calibre -o jsonpath='{.items[0].spec.securityContext}'
kubectl get pod -n calibre -l app.kubernetes.io/name=calibre -o jsonpath='{.items[0].spec.containers[0].securityContext}'

# Verify non-root execution
kubectl exec -n calibre -l app.kubernetes.io/name=calibre -- id

# Check authentication enforcement
kubectl port-forward -n calibre svc/calibre 28080:8080 &
sleep 3
curl -s -o /dev/null -w "%{http_code}" http://localhost:28080/opds
curl -s -o /dev/null -w "%{http_code}" -u wronguser:wrongpass http://localhost:28080/opds
```
