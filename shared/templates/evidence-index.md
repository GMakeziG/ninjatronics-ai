# Evidence Index: Project / Release / Audit Period

- Index ID: EV-NNNN
- Scope: project, release, or assessment this index covers
- Period covered: start — end
- Maintainer: Archivist
- Last updated: YYYY-MM-DD

## Purpose

Single point of reference mapping claims to proof. Every entry must be
verifiable by an independent reviewer without asking the original author.

## Evidence standards

Every entry must be:

- Timestamped (when it was generated, not when it was filed)
- Traceable (what produced it: command, tool, person)
- Scoped (what system/environment it applies to)
- Repeatable (how to regenerate it, where possible)
- Verified (Archivist confirmed the artifact exists at the stated location)

Never index evidence that has not been verified to exist.
