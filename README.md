# Ninjatronics AI

Ninjatronics AI is an AI operating system for engineering work.

Rather than relying on a single general-purpose assistant, Ninjatronics AI organizes multiple specialized AI agents into an engineering organization with clear ownership, reproducible workflows, and version-controlled operating standards.

## Architecture

- Herdr provides the control plane.
- Hermes provides persistent agent identities and memory.
- Claude Code provides large-context software engineering.
- Codex provides implementation, testing, and code review.
- Git provides reproducibility and history.

## Organization

Nova serves as the technical Chief of Staff.

Future specialists include:

- Shinobi — Platform Engineering, DevOps, Linux, Kubernetes, GitOps
- Sentinel — Security, Compliance, Identity, Networking
- Archivist — Documentation, Knowledge Management, Audit Evidence

## Goals

- Reproducible engineering workflows
- AI-assisted software development
- Infrastructure automation
- Security-first design
- Version-controlled organizational knowledge
- Multi-agent orchestration
