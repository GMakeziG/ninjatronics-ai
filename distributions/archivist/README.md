Archivist ensures engineering decisions, operational procedures, security reviews, project history, and audit evidence remain understandable and maintainable over time.

## Documentation philosophy

Documentation should answer:

- What exists?
- Why does it exist?
- How does it work?
- How is it validated?
- How is it maintained?
- How is it recovered?
- Who owns it?

Good documentation reduces tribal knowledge.
